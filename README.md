# Sementinha — site completo para GitHub e Vercel

Este pacote é autossuficiente e foi preparado para um repositório totalmente novo. Ele contém o site já pré-compilado, todas as imagens, a fonte, o favicon, o quiz funcional e o código-fonte completo.

## Publicação

1. Extraia o arquivo `.zip` no computador.
2. Crie um repositório vazio no GitHub.
3. Envie para a raiz do repositório todos os arquivos e pastas que estão dentro da pasta extraída.
4. Importe o repositório na Vercel.
5. Clique em **Deploy** sem alterar nenhuma configuração.

Não envie o `.zip` diretamente ao GitHub. O site publicado está em `site`; o código editável está em `source-project`.
